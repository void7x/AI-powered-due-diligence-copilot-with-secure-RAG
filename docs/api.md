# REST API

Base URL: `http://localhost:8000` (dev). Authenticated routes expect `Authorization: Bearer <token>`.
Interactive docs: `http://localhost:8000/docs` (Swagger UI, generated by FastAPI).

## Auth
| Method | Path | Notes |
|---|---|---|
| POST | `/api/auth/register` | `{email, password, name}` → token |
| POST | `/api/auth/login` | `{email, password}` → `{access_token}` |
| GET | `/api/auth/me` | current user |

## Companies
| Method | Path | Notes |
|---|---|---|
| GET/POST | `/api/companies` | list / create workspace |
| GET/PATCH/DELETE | `/api/companies/{id}` | detail / update / delete |
| GET | `/api/companies/{id}/overview` | scorecards, trends, top risks/opps, recent docs |
| GET | `/api/dashboard` | cross-company totals + recent activity |

## Documents
| Method | Path | Notes |
|---|---|---|
| POST | `/api/companies/{id}/documents` | multipart `files` (+ optional `document_type`, `fiscal_year`); validation + SHA-256 dedupe |
| GET | `/api/companies/{id}/documents` | list; filters `q`, `document_type`, `fiscal_year`, `status`, `sort` |
| GET | `/api/documents/{id}` | metadata incl. status |
| GET | `/api/documents/{id}/pages` | page-aware extracted text |
| GET | `/api/documents/{id}/file` | authenticated original-file response |
| DELETE | `/api/documents/{id}` | delete document and stored file |
| POST | `/api/documents/{id}/process` | re-start processing job |

## Analysis & jobs
| Method | Path | Notes |
|---|---|---|
| POST | `/api/companies/{id}/analyze` | run full analysis asynchronously → `{job_id}` |
| GET | `/api/jobs/{job_id}` | `{status, steps, current_step, progress, result, error}`; owner-scoped |

## Chat & search
| Method | Path | Notes |
|---|---|---|
| POST | `/api/companies/{id}/chat` | `{question, session_id?, document_types?, fiscal_years?}` → structured answer + citations |
| GET | `/api/companies/{id}/chat/messages` | latest session history |
| GET | `/api/companies/{id}/chat/sessions` | user's sessions for the company |
| GET | `/api/companies/{id}/search` | `?q=&document_type=&fiscal_year=` → page-aware hits |

## Reports
| Method | Path | Notes |
|---|---|---|
| POST | `/api/companies/{id}/report` | generate and persist a fresh DD report |
| GET | `/api/companies/{id}/reports` | list report summaries |
| GET | `/api/reports/{id}` | full 13-section report content |
| GET | `/api/reports/{id}/html` | authenticated standalone printable HTML |

The standalone HTML endpoint requires the same bearer-header authentication as other protected routes. The frontend fetches it with the auth header and opens the returned HTML as a browser blob URL; tokens are not put in the query string.

## Health
| Method | Path | Notes |
|---|---|---|
| GET | `/api/health` | returns healthy only when database connectivity is available; DB outage returns HTTP 503 |

### Error format

Application errors use a structured payload such as `{"error": {"code": "...", "message": "...", "details": {...}}}` with an appropriate HTTP status (400/401/403/404/409/413/422/500).
