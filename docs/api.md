# REST API

Base URL: `http://localhost:8000` (dev). All authenticated routes expect `Authorization: Bearer <jwt>`.
Interactive docs: `http://localhost:8000/docs` (Swagger UI, generated by FastAPI).

## Auth
| Method | Path | Notes |
|---|---|---|
| POST | `/api/auth/register` | `{email, password, name}` → token |
| POST | `/api/auth/login` | `{email, password}` → `{access_token}` |
| GET | `/api/auth/me` | current user |

## Companies
| Method | Path | Notes |
|---|---|---|
| GET/POST | `/api/companies` | list / create workspace |
| GET/PATCH/DELETE | `/api/companies/{id}` | detail / update / delete (cascades) |
| GET | `/api/companies/{id}/overview` | scorecards, trends, top risks/opps, recent docs |
| GET | `/api/dashboard` | cross-company totals + recent activity |

## Documents
| Method | Path | Notes |
|---|---|---|
| POST | `/api/companies/{id}/documents` | multipart `files` (+ optional `document_type`, `fiscal_year`); validation + SHA-256 dedupe |
| GET | `/api/companies/{id}/documents` | list; filters `q`, `document_type`, `fiscal_year`, `status`, `sort` |
| GET | `/api/documents/{id}` | metadata incl. status |
| GET | `/api/documents/{id}/pages` | page-aware text |
| GET | `/api/documents/{id}/file` | authenticated original-file download |
| DELETE | `/api/documents/{id}` | delete |
| POST | `/api/documents/{id}/process` | (re)start processing job |

## Analysis & jobs
| Method | Path | Notes |
|---|---|---|
| POST | `/api/companies/{id}/analyze` | run full analysis → `{job_id}` |
| POST | `/api/companies/{id}/report` | generate DD report |
| GET | `/api/jobs/{job_id}` | `{status, steps, current_step, progress, result, error}` |

## Financials
| Method | Path | Notes |
|---|---|---|
| GET | `/api/companies/{id}/financials` | periods, ratios, trends |
| GET | `/api/companies/{id}/financials/changes` | `?base=&target=` period compare |

## Risks / opportunities / questions
| Method | Path |
|---|---|
| GET | `/api/companies/{id}/risks` |
| GET | `/api/companies/{id}/opportunities` |
| GET | `/api/companies/{id}/inconsistencies` |
| GET | `/api/companies/{id}/questions` |

## Chat & search
| Method | Path | Notes |
|---|---|---|
| POST | `/api/companies/{id}/chat` | `{question, session_id?}` → `{answer, confidence, claims[], citations[], insufficient_evidence, session_id, message_id}` |
| GET | `/api/companies/{id}/chat/messages` | history |
| GET | `/api/companies/{id}/search` | `?q=&document_type=&fiscal_year=` → hits with page + excerpt |

## Reports
| Method | Path | Notes |
|---|---|---|
| GET | `/api/companies/{id}/reports` | list summaries |
| GET | `/api/reports/{id}` | full 13-section content |
| GET | `/api/reports/{id}/html?token=` | standalone printable HTML (token auth for print window) |
| GET | `/api/reports/{id}/json` | machine-readable export |

### Error format

All errors return `{"code": "...", "message": "...", "details": {...}?}` with appropriate HTTP status (400/401/403/404/409/413/422/500).
